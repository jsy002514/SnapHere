# 게시글 등록 결과 및 오류 안내

적용 결정: DEC-20260916-006, DEC-20260916-007

## 등록 성공 후 실패 안내가 뜬 원인

백엔드의 `CreatePostResponse`는 `data.postId`를 반환한다. 앱이 이를 `data.post.summary.postId`로 읽다가 예외를 내면서, 서버에는 게시글이 저장됐는데 작성 화면에 실패 안내가 남았다.

앱이 최상위 `postId`를 읽도록 수정했다. `mediaStatus: PROCESSING`은 사진 후처리 중인 **등록 성공**이며 정상 완료 화면으로 이동한다. 선택적인 뱃지 정보가 없거나 잘못돼도 게시글 등록 성공을 취소하지 않는다. 완료 화면의 게시글 보기·홈 이동은 기존 흐름을 유지한다.

## 사용자에게 표시하는 문구

서버의 오류 코드를 우선 사용하고, 코드가 없으면 HTTP 상태와 실패 단계를 함께 판단한다. 서버 원문이나 사진 저장소 주소를 사용자에게 그대로 노출하지 않는다. 용량 한도 등 서버 설정에 따라 달라지는 수치는 추측하지 않는다.

| 약관 미동의 | 서비스 이용약관 동의가 필요해요. 약관에 동의한 뒤 등록해 주세요. |
| 탈퇴·존재하지 않는 계정 | 현재 계정으로 게시글을 등록할 수 없어요. 계정 상태를 확인해 주세요. |

| 업로드 준비 시간 초과 | 업로드 준비 시간이 초과됐어요. 잠시 후 다시 시도해 주세요. |

| 계정의 등록 제한 | 현재 게시글 등록이 제한된 계정이에요. 이용 제한 안내를 확인해 주세요. |

| 기타 입력 정보 오류 | 등록 정보가 올바르지 않아요. 사진·장소·태그와 작성 내용을 확인해 주세요. |
| 기타 등록 권한 없음 | 게시글을 등록할 권한이 없어요. 계정 상태를 확인해 주세요. |
| 기타 상태 충돌 | 현재 상태에서는 등록할 수 없어요. 내 게시글과 선택한 정보를 확인해 주세요. |
| 등록 요청 후 연결 끊김·시간 초과·5xx·응답 손상 | 등록 결과를 확인하지 못했어요. 이미 등록됐을 수 있으니 내 게시글을 먼저 확인해 주세요. |

마지막 상황은 실패로 확정하지 않는다. 저장은 끝났지만 응답 전달에 실패했을 수 있다. 자동 재등록은 수행하지 않으며, 처리 중 또는 완료 후 연속 제출도 차단한다. 오류 시 현재 작성 내용을 유지하고, 사용자가 다시 제출해 성공하면 오류 안내를 지운다.

`POST_MEDIA_PROCESSING` 오류 코드와 정상 성공 응답의 `mediaStatus: PROCESSING`은 서로 다르다. 정상 응답에 게시글 번호가 있으면 완료로 처리한다. 문구는 백엔드에 정의된 오류에 대응하며 모든 제한 정책이 현재 서버에서 활성화돼 있다는 뜻은 아니다.

## 확인 범위

- HTTP 응답을 대체한 회귀 테스트로 실제 서버 응답 구조의 완료 전환, 뱃지 누락·손상, 단계별 통신 오류, 명시적 서버 거절, 중복 제출 방지를 확인한다.
- 화면 테스트로 완료 후 상세·홈 이동, 구체적 오류 표시, 작성 내용 유지, 재시도 성공 시 오류 해제를 확인한다.
- 운영 서버에 테스트 게시글을 생성하지 않는다. 실제 게시 결과 확인은 업데이트된 앱에서 사용자가 다음 게시글을 등록할 때 진행한다.

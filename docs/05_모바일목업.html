실시간·진행중 상태 표시에는 Lotus Pink를 재사용했습니다. 팔레트를 5색에서 늘리지 않기로 한 결정을 지키기 위해서입니다.

1. 홈 (지도) — 랜딩 화면

앱을 켜면 바로 이 화면입니다. 로그인 화면은 진입 경로에 없고, 비로그인 상태로 지도·검색·게시물을 다 볼 수 있습니다. 시도 영역이 버튼이며 얇고 긴 지역을 위해 핀을 함께 놓았습니다. 레이어는 지역 / 트래픽 / 인기 사진 세 가지입니다.

2. 지역 게시판

홈 지도에서 지역을 눌러 진입합니다. 최신 / 인기순 / 태그별 3탭 구조입니다.

3. 업로드

별도 화면으로 분리했습니다. 장소 선택이 작성 화면 안에 있어야 인증·랭킹·방문기록이 동작합니다.

4. 커뮤니티

검색이 독립 탭에서 이 안으로 들어왔습니다. 인기 사진·추천·랭킹·팔로잉 피드가 모입니다.

5. 이벤트

지자체 행사. 관광공사 축제 데이터가 기반이고, 행사 기간이 자동 태그 추천에도 쓰입니다.

6. 게시물 상세

작성자의 인기 지수·등급이 함께 보이고, 자동 태그가 그대로 노출됩니다.

7. 마이페이지 · 알림

인기 지수·등급·개인 SNS가 프로필 상단에 옵니다.

8. 계정 — 필요할 때만 진입

로그인 화면은 랜딩이 아닙니다. 게시글을 올리려 할 때, 그리고 좋아요·댓글·팔로우·저장을 시도할 때만 시트로 올라옵니다.

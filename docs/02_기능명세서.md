# 기능 명세서 (v3)

> 내비게이션 5탭 — ① 홈(지도) ② 커뮤니티 ③ 업로드 ④ 이벤트 ⑤ 마이페이지

> **랜딩 = 지도.** 로그인은 게시글을 올리려 할 때 비로소 필요하다.

## 0. 홈 (지도) [nav ①]

### 0.1 지도 기본 레이어

**시도 영역 표시**

- 대한민국 지도에서 시도별 영역이 각각 버튼 역할  
- 영역을 누르면 그 지역 게시판으로 이동

- 화면 전환: - 영역 탭: 5. 지역 게시판
- 비고: 논의사항 1. 충청북도처럼 얇고 긴 지역은 영역 탭이 어렵다는 문제 제기가 있었음. 서버가 시도별 라벨 좌표를 주면 앱이 그 지점에 별도 터치 타겟(핀)을 놓을 수 있음. 영역 + 핀을 함께 두는 방식 권장.

**시도별 활동량 농도**

- 시도별 최근 활동량을 색 농도로 표시

- 화면 전환: 현재 페이지 유지

### 0.2 트래픽 레이어

**실시간 트래픽 표시**

- 최근 1시간 활동을 원 크기로 표시(버블)  
- 원이 클수록 게시물이 많은 구역

- 화면 전환: - 원 탭: 0.4 구역 요약
- 비고: [확정] 실시간 = 1분 캐시 + 앱 60초 폴링. 웹소켓·SSE는 사용하지 않음.

**데이터 부족 시 폴백**

- 최근 1시간 게시물이 적으면 자동으로 24시간 기준으로 전환  
- '최근 24시간 기준' 라벨 표시

- 화면 전환: 현재 페이지 유지
- 비고: ★ 시연 대비 필수. 초기에 지도가 텅 비면 실시간 지도 컨셉 자체가 무너짐.

### 0.3 인기 사진 레이어

**사진 마커 표시**

- 구역별 대표 사진을 썸네일 마커로 지도에 표시  
- 마커를 누르면 해당 게시물로 이동

- 화면 전환: - 마커 탭: 6. 게시물 상세
- 비고: 썸네일 URL을 집계 단계에서 미리 저장해 마커를 바로 그릴 수 있게 함

**레이어 전환**

- 기본 / 트래픽 / 인기 사진 레이어를 전환

- 화면 전환: 현재 페이지 유지
- 비고: 논의사항 2. 레이어를 사용자가 직접 전환할지, 시간에 따라 자동 페이드 인·아웃할지, 확대 단계별로 자동 전환할지 확정 필요. 자동 전환은 보기엔 좋지만 사용자가 원하는 정보를 못 볼 수 있음.

### 0.4 구역 요약

**구역 정보 표시**

- 선택한 구역의 게시물 수·방문자 수·대표 장소를 바텀시트로 표시

- 화면 전환: - 장소 선택: 7. 장소 상세 / - 더블탭: 확대 후 재조회

### 0.5 주변 탐색

**현재 위치 주변 조회**

- 현재 GPS 기준 반경 안의 장소를 거리순으로 표시

- 화면 전환: - 장소 선택: 7. 장소 상세
- 비고: 반경 기본 500m, 최대 20km

### 0.6 비로그인

**둘러보기 모드**

- 로그인 없이 지도·검색·게시물 조회 가능  
- 쓰기 동작 시도 시 로그인 시트 노출

- 화면 전환: 로그인 시트: 10.1 로그인

## 1. 커뮤니티 [nav ②]

### 1.1 검색

**통합 검색**

- 장소 / 게시물 / 사용자 / 태그를 검색  
- 검색어 입력 전에는 인기 검색어와 최근 검색어 표시

- 화면 전환: - 장소: 7. 장소 상세 / - 게시물: 6. 게시물 상세 / - 사용자: 8. 프로필
- 비고: [변경] 검색이 독립 탭에서 커뮤니티 탭 안으로 이동함

**태그 검색**

- 해시태그로 게시물을 검색

- 화면 전환: - 선택: 6. 게시물 상세

### 1.2 인기·추천

**전국 인기 사진**

- 전국 기준 인기 사진을 격자로 표시  
- 24시간 / 일주일 / 한달 / 전체 기간 전환

- 화면 전환: - 선택: 6. 게시물 상세
- 비고: 논의사항 3. 인기 산정 기준 확정 필요. 시간에 따라 상위권 노출 점수를 감쇠시키는 방식(핫스코어)과 기간별로 나눠 각각 순위를 매기는 방식이 있음. 현재는 후자로 설계함.

**추천 장소**

- 지금 볼 만한 장소를 추천하여 표시  
- 추천 사유를 함께 표시

- 화면 전환: - 선택: 7. 장소 상세
- 비고: 데이터가 부족한 초기에는 운영자 지정 장소로 채워짐

**랭킹**

- 지역·기간·테마별 장소 랭킹과 순위 변동 표시  
- 사용자가 등록한 장소만 대상으로 한 숨은 명소 랭킹 별도 제공

- 화면 전환: - 선택: 7. 장소 상세
- 비고: 숨은 명소 랭킹은 공모전 차별 포인트로 활용 예정

### 1.3 팔로잉

**팔로잉 피드**

- 팔로우한 사용자들의 게시물만 모아서 표시

- 화면 전환: - 선택: 6. 게시물 상세
- 비고: [확정] 별도 탭 없이 커뮤니티 안에 배치. 주된 활용은 목록 가중치(5.2)이고 이 화면은 보조 수단.

## 2. 업로드 [nav ③]

### 2.0 진입

**업로드 화면 진입**

- 내비게이션 중앙 버튼을 누르면 별도 화면으로 전환  
- 팝업·바텀시트가 아닌 전체 화면

- 화면 전환: - 지금 촬영: 2.1 카메라 / - 이전 사진: 2.2 갤러리 선택
- 비고: [변경] 바텀시트에서 별도 화면으로 분리됨

### 2.1 카메라

**지금 촬영하기**

- 카메라를 실행해 즉시 촬영  
- 촬영 방식을 '카메라'로 서버에 전달

- 화면 전환: - 촬영 완료: 2.3 게시글 작성
- 비고: 논의사항 4. 촬영 방식(카메라/갤러리) 구분이 현장 인증 판정의 핵심 입력값. 앱이 이 값을 정확히 보내지 않으면 최고 등급 인증을 부여할 수 없음.

### 2.2 갤러리 선택

**이전 사진 업로드**

- 갤러리에서 사진을 최대 10장 선택  
- 각 사진의 촬영 위치·촬영 시각(EXIF)을 함께 추출

- 화면 전환: - 선택 완료: 2.3 게시글 작성
- 비고: 위치 정보가 없는 사진은 위치 미확인으로 판정되어 랭킹·방문 기록에서 제외됨 → 선택 시점에 안내 필요

**영상 선택**

- 영상을 첨부할 수 있음 (길이·용량 제한 적용)

- 화면 전환: - 선택 완료: 2.3 게시글 작성
- 비고: 논의사항 5. 영상 제한값 확정 필요(현재 안: 100MB · 60초). 서버에서 썸네일을 추출해야 하고 전송 비용이 이미지와 비교가 안 되므로 CDN 사용 여부까지 함께 결정해야 함.

### 2.3 게시글 작성

**장소 선택**

- 촬영 좌표 기준 주변 장소 후보를 거리순으로 표시  
- 현장 인증 가능 여부 표시  
- 후보가 없으면 새 장소 만들기

- 화면 전환: - 새 장소: 2.4 새 장소 만들기
- 비고: ★ 중요 장소를 정하지 못하면 인증 등급·랭킹·방문 기록이 전부 동작하지 않음. 작성 화면 안에 반드시 장소 선택 영역이 있어야 함.

**태그 자동 채우기**

- 위치와 외부 데이터 연동으로 태그가 자동으로 채워짐  
  · 지역 태그 (예: #경주)  
  · 분류 태그 (예: #축제)  
  · 진행중 행사 태그 (예: #2026 oo축제)  
- 사용자가 선택 해제 가능

- 화면 전환: 현재 페이지 유지
- 비고: ★ 와이어프레임의 핵심 요구. 진행중 행사 태그는 행사 기간과 좌표 반경이 모두 겹쳐야 추천되므로 관광공사 축제 데이터 적재가 선행되어야 함.

**태그 직접 추가**

- 추천 태그 외에 사용자가 태그를 직접 입력

- 화면 전환: 현재 페이지 유지
- 비고: 자동 추천 태그와 직접 입력 태그를 구분해 저장 → 추천 채택률 측정

**본문 입력**

- 제목·본문 입력 (둘 중 하나는 필수)  
- 카테고리 선택

- 화면 전환: - 사진 게시: 2.5 게시 완료
- 비고: 사진만 올리는 경우를 위해 제목은 선택값

### 2.4 새 장소 만들기

**장소 등록**

- 관광지가 아닌 장소를 이름과 현재 좌표로 등록  
- 하루 5개까지 생성 가능

- 화면 전환: - 생성 완료: 2.3 게시글 작성
- 비고: 논의사항 6. 반경 100m 안에 같은 이름이 있으면 기존 장소를 재사용함. 중복 판정 기준을 어디까지 느슨하게 할지 확정 필요.

### 2.5 게시 완료

**지도에 반영**

- 게시 후 내 사진이 지도에 마커로 표시되는 화면으로 이동  
- 갱신 주기와 무관하게 즉시 반영

- 화면 전환: - 확인: 0. 홈 (지도)
- 비고: 와이어프레임의 '업로드 후' 화면. 시연 중 '지금 올리면 바로 뜨나요'에 대응

**인증 등급·한도 표시**

- 위치 인증 등급 배지 표시 (현장 인증 / 위치 확인 / 위치 미확인)  
- 오늘 남은 업로드 가능 수 표시

- 화면 전환: - 확인: 6. 게시물 상세
- 비고: 배지 명칭은 기술 용어(GPS) 대신 신뢰도 표현으로 통일

## 3. 이벤트 [nav ④]

### 3.1 행사 목록

**진행중 행사**

- 현재 진행중인 지자체 행사를 목록으로 표시  
- 지역 필터 제공

- 화면 전환: - 선택: 3.3 행사 상세
- 비고: [신규] 관광공사 축제·행사 데이터 기반

**예정 행사**

- 곧 시작하는 행사를 시작일 순으로 표시

- 화면 전환: - 선택: 3.3 행사 상세

### 3.2 주변 행사

**내 주변 행사**

- 현재 위치 주변에서 진행중인 행사를 조회

- 화면 전환: - 선택: 3.3 행사 상세
- 비고: 주변 장소 조회와 같은 공간 쿼리를 재사용

### 3.3 행사 상세

**행사 정보**

- 기간·장소·주최·소개·이미지 표시

- 화면 전환: - 지도 보기: 0. 홈 (지도)

**관련 게시물**

- 이 행사에 참여한 사용자의 사진·영상을 함께 표시

- 화면 전환: - 선택: 6. 게시물 상세
- 비고: 행사 태그 또는 장소 연결로 판정

**행사에 사진 올리기**

- 행사 상세에서 바로 업로드 화면으로 이동하고 행사 태그가 자동 선택됨

- 화면 전환: - 이동: 2. 업로드
- 비고: 논의사항 7. 영상 업로드를 이벤트에서만 허용할지 전체 게시물에 허용할지 확정 필요. 전체 허용 시 전송 비용과 저장 용량이 빠르게 커짐.

## 4. 마이페이지 [nav ⑤]

### 4.1 프로필

**프로필 정보**

- 프로필 이미지·이름·인기 지수·등급 표시  
- 개인 SNS 링크 표시

- 화면 전환: - 팔로워·팔로잉: 8.2 / 8.3 / - 수정: 4.5 설정
- 비고: 논의사항 8. 등급 명칭과 구간 확정 필요. 구간을 좁게 잡으면 초반에 등급이 급하게 올라 의미가 희석됨.

**개인 SNS 링크**

- 인스타그램·유튜브·블로그 링크를 등록하고 프로필에 노출

- 화면 전환: 외부 앱·브라우저 호출
- 비고: ★ 외부 링크는 허용 도메인 검증이 필요. 검증 없이 받으면 피싱 링크 유포 통로가 됨.

**알림 진입·뱃지**

- 읽지 않은 알림 수를 뱃지로 표시하고 탭하면 알림함으로 이동

- 화면 전환: - 탭: 9. 알림
- 비고: 내비게이션에 알림 탭이 없어 마이페이지에 배치

### 4.2 내 게시물

**게시물 그리드**

- 내가 작성한 게시물을 높이가 다른 격자로 표시  
- 인증 등급별 필터 제공

- 화면 전환: - 선택: 6. 게시물 상세
- 비고: 논의사항 9. 사진 규격이 1:1 / 16:9 등으로 다양해 가변 높이 격자(masonry)를 쓰기로 논의됨. 구현 난도가 있으므로 1차는 정사각 고정, 2차에 가변으로 갈지 확정 필요. 서버는 어느 쪽이든 대표 미디어 비율을 제공함.

### 4.3 방문 기록

**방문 기록·통계**

- 방문한 장소를 최신순으로 표시  
- 방문한 지역 수·장소 수와 지역별 분포를 지도로 표시

- 화면 전환: - 선택: 7. 장소 상세
- 비고: '17개 시도 중 8곳 방문' 형태로 수집 동기 부여

### 4.4 저장 목록

**저장한 게시물·장소**

- 저장한 게시물과 장소를 구분하여 조회

- 화면 전환: - 선택: 6. / 7.

### 4.5 설정

**프로필 수정**

- 닉네임·소개글·프로필 이미지·SNS 링크·언어 수정

- 화면 전환: 완료: 4. 마이페이지

**알림 설정**

- 좋아요·댓글·팔로우·팔로잉 새 글 알림을 개별로 켜고 끔

- 화면 전환: 현재 페이지 유지

**비밀번호 변경**

- 현재 비밀번호 확인 후 새 비밀번호로 변경 (일반 로그인 계정만)

- 화면 전환: 완료: 4.5 설정
- 비고: 변경 시 다른 기기의 세션을 전부 종료할 것

**로그아웃**

- 현재 기기 또는 전체 기기에서 로그아웃

- 화면 전환: - 완료: 0. 홈 (둘러보기 모드)

### 4.6 계정 삭제

**삭제 전 안내**

- 사라지는 데이터(게시물·미디어·댓글·팔로워·방문 수)를 숫자로 표시

- 화면 전환: - 계속: 4.6 콘텐츠 처리 선택
- 비고: 오조작 탈퇴를 줄이기 위한 단계

**콘텐츠 처리 선택**

- 게시물을 남길지(작성자만 익명 표시) 전부 삭제할지 선택

- 화면 전환: - 확인: 4.6 삭제 실행
- 비고: 논의사항 10. 기본 선택값 확정 필요. '남기기'가 기본이면 랭킹 데이터는 보존되지만 사용자 기대와 다를 수 있음.

**삭제 실행**

- 개인정보는 즉시 파기되고 30일 뒤 계정이 완전히 삭제됨  
- 30일 이내 재로그인 시 복구 가능

- 화면 전환: - 완료: 0. 홈 (둘러보기 모드)
- 비고: 복구해도 이메일·닉네임·프로필 이미지는 돌아오지 않음 → 안내 문구 필수

## 5. 지역 게시판

### 5.1 최신 탭

**최신 게시물**

- 해당 지역의 게시물을 최신순으로 가변 높이 격자로 표시

- 화면 전환: - 선택: 6. 게시물 상세
- 비고: 홈 지도에서 지역 영역을 눌러 진입

### 5.2 인기순 탭

**기간별 인기 게시물**

- 24시간 / 일주일 / 한달 / 전체 기간별 인기 게시물 표시

- 화면 전환: - 선택: 6. 게시물 상세
- 비고: 와이어프레임에서 '아마 후자(기간 분리)일 것 같다'고 정리된 방식으로 설계함

**게시판 내 검색**

- 이 지역 게시물 안에서 검색

- 화면 전환: 결과: 현재 페이지 유지
- 비고: 커뮤니티 탭의 전체 검색과 별개. 지역이 고정된 검색

**팔로잉 가중치**

- 팔로우한 사용자의 게시물이 위쪽에 노출되고 '팔로잉' 뱃지 표시

- 화면 전환: - 선택: 6. 게시물 상세
- 비고: [확정] 팔로우 기능의 주 활용처.  주의 1. 가중치가 세면 팔로잉 글만 보여 새로운 발견이 막힘 → 상수로 분리해 튜닝. 주의 2. 개인화는 첫 페이지에만 적용. 전체 적용 시 사용자마다 순서가 달라 목록 캐시를 못 씀. 주의 3. 팔로잉이 0명이면 효과가 없으므로 추천 사용자 노출이 필요.

### 5.3 태그별 탭

**지역 태그 목록**

- 이 지역에서 많이 쓰인 태그를 게시물 수 순으로 표시  
  (예: #한옥마을 #임실치즈축제 #진안홍삼축제 #군산)

- 화면 전환: - 태그 선택: 5.3 태그 게시물
- 비고: 매 요청 집계하지 않고 배치로 미리 만든 집계를 읽음

**태그 게시물 목록**

- 선택한 태그가 달린 게시물을 표시

- 화면 전환: - 선택: 6. 게시물 상세

## 6. 게시물 상세

### 6.1 본문

**미디어·본문 조회**

- 사진·영상 스와이프, 본문, 작성자, 장소, 태그, 인증 배지 표시

- 화면 전환: - 작성자: 8. 프로필 / - 장소: 7. 장소 상세 / - 태그: 5.3 태그 게시물

**좋아요·저장·공유**

- 좋아요 등록/취소, 저장, 외부 공유

- 화면 전환: 비로그인: 10.1 로그인 시트
- 비고: 좋아요 시 작성자에게 푸시 알림 발송(자기 글 제외)

**수정·삭제·신고**

- 자신의 게시물 수정·삭제, 타인 게시물 신고

- 화면 전환: - 삭제 완료: 직전 목록
- 비고: 위치와 인증 등급은 수정 불가 — 인증 체계 보호 / 신고 3회 누적 시 자동 숨김

### 6.2 댓글

**댓글 작성·조회·수정·삭제**

- 댓글과 대댓글(1단계) 작성·조회  
- 자신의 댓글 수정·삭제, 댓글 좋아요

- 화면 전환: - 작성자: 8. 프로필
- 비고: 대댓글이 있는 댓글 삭제 시 '삭제된 댓글입니다'로 표시하고 자식은 유지

## 10. 계정

### 10.1 로그인

**아이디·비밀번호 로그인**

- 아이디와 비밀번호로 로그인  
- 성공 시 직전 화면으로 복귀

- 화면 전환: - 회원가입: 10.2 / - 성공: 직전 화면
- 비고: 아이디 오류와 비밀번호 오류를 구분해 응답하지 않음(계정 존재 여부 노출 방지)

**구글 계정으로 로그인**

- 구글 계정 선택 후 로그인  
- 최초면 프로필 정보로 자동 가입

- 화면 전환: - 신규: 10.3 프로필 초기 설정 / - 탈퇴 유예 계정: 10.4 계정 복구
- 비고: [확정] 소셜 로그인은 구글 단독. 다른 제공자는 추가하지 않는다.

**자동 로그인**

- 저장된 토큰으로 자동 로그인  
- 만료 시 재발급 후 원래 요청 재시도

- 화면 전환: - 재발급 실패: 0. 홈 (둘러보기 모드)
- 비고: 앱은 401 응답 시 자동 재발급 인터셉터 구현 필요

### 10.2 회원가입

**아이디·비밀번호 입력**

- 아이디 입력 후 중복 확인  
- 비밀번호와 비밀번호 확인 입력

- 화면 전환: - 가입 완료: 10.3 프로필 초기 설정
- 비고: 논의사항 12. 와이어프레임에 이메일 입력란이 없음. 이메일을 받지 않으면 비밀번호를 잃어버린 사용자를 복구할 방법이 전혀 없다. 가입 시 이메일을 받을지 확정 필요.

**입력 규칙 안내**

- 아이디·비밀번호 형식 규칙을 화면에서 안내하고 실시간 검증

- 화면 전환: 현재 페이지 유지
- 비고: 비밀번호 정책 확정 필요 (현재 안: 8자 이상 + 영문·숫자 조합)

### 10.3 프로필 초기 설정

**닉네임·약관**

- 닉네임 설정  
- 최초 업로드 전 이용 약관에 1회 동의

- 화면 전환: - 완료: 0. 홈
- 비고: 약관 문안 확보 필요

### 10.4 계정 복구

**탈퇴 계정 복구**

- 탈퇴 후 30일 이내 재로그인 시 복구 안내  
- 복구 시 게시물·방문 기록 유지

- 화면 전환: - 복구/취소: 0. 홈
- 비고: 이메일·닉네임·프로필 이미지는 이미 파기되어 복구되지 않음 → 안내 문구에 반드시 명시
